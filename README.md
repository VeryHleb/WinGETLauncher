# WinGET Launcher

**GUI-лаунчер для пакетной установки программ через `winget`** (Windows 10 / 11).

**Последняя стабильная версия:** `1.2`

---

## ✨ Возможности

- 🖥️ **Нативный GUI** на Win32 API — без внешних зависимостей, в один компактный `.exe`
- 🧠 **Автоопределение ОС:** проверка минимальной версии Windows (10 20H2+)
- ✅ **Выбор приложений** через удобные галочки в списке
- 📂 **Категории приложений** — структурированный выбор по разделам («Общение», «Игры» и др.)
- 🔍 **Поиск через winget** — встроенное окно поиска с возможностью добавления в репозиторий
- 🔄 **Net Install автообновление** — лаунчер сам проверяет версии и скачивает необходимые скрипты с GitHub
- 📦 **Нативная работа с ZIP** — использование штатного PowerShell `Expand-Archive` без необходимости держать сторонние утилиты типа `7-Zip`
- 📊 **Прогресс-бар N из N** — наглядное отображение установки выбранных пакетов
- 📝 **Живой вывод** `.bat` в правую панель лаунчера
- 🎨 **Стилизация под Windows 7 Aero** — градиенты, кнопки и шрифт Segoe UI
- 📋 **Файл-репозиторий** `repositories.txt` — легкое управление списком доступного софта
- 🚀 **Автозапуск TgWsProxy** — поддержка автоматического запуска утилит при выборе Telegram
- 📁 **Логирование** в `logs\` с автоочисткой старше 30 дней
- 🔒 **UAC-манифест** — автоматический запрос прав администратора при старте

| ОС | Лаунчер | Пакетный менеджер | Установка |
|---|---|---|---|
| **Windows 10 20H2+** | ✅ | **winget** | ✅ **полная поддержка** |
| **Windows 11** | ✅ | **winget** | ✅ **полная поддержка** |

> **Важно:** Поддержка Windows 7, 8.1 и старых сборок Windows 10 прекращена. Лаунчер требует наличия `winget` (App Installer) в системе.

## 🚀 Быстрый старт (Net Install)

1. Скачайте **`net_install.bat`** из раздела **Releases** или из корня репозитория.
2. Положите его в пустую папку (например, `D:\WinGETLauncher`).
3. Запустите `net_install.bat` **от имени Администратора**. 
4. Скрипт скачает файлы по списку `source/net_install.txt`, развернет зависимости (`Winget.zip`) с помощью встроенного в Windows PowerShell, запустит `launcher.exe` и **самоликвидируется**.
5. Выберите нужные программы и нажмите **«Установить выбранное»**.
