# WinGET Launcher

**GUI-лаунчер для пакетной установки программ через `winget`** (Windows 10 / 11).

**Последняя стабильная версия:** `1.0`

---

## ✨ Возможности

- 🖥️ **Нативный GUI** на Win32 API — без зависимостей, в один `.exe`
- 🧠 **Автоопределение ОС:** проверка минимальной версии Windows (10 20H2+)
- ✅ **Выбор приложений** через галочки в списке
- 📂 **Категории приложений** — «Общение», «Игры», «Мультимедиа» и др.
- 🔍 **Поиск через winget** — отдельное окно с результатами и кнопкой «Добавить в репозиторий»
- 🔄 **Net Install автообновление** — лаунчер сам скачивает нужные скрипты, `winget` и обновления с GitHub
- 📊 **Прогресс-бар N из N** — точно по числу выбранных пакетов
- 📝 **Живой вывод** `.bat` в правую панель
- 🎨 **Стилизация под Windows 7 Aero** — градиентный фон, glossy-кнопки, Segoe UI
- 📋 **Файл-репозиторий** `repositories.txt` — легко добавлять свои пакеты
- 🚀 **Автозапуск TgWsProxy** — если выбран Telegram
- 📁 **Логирование** в `logs\` с автоочисткой старше 30 дней
- 🔒 **UAC-манифест** — запрос админ-прав при старте

## 🖥️ Поддерживаемые системы

| ОС | Лаунчер | Пакетный менеджер | Установка |
|---|---|---|---|
| **Windows 10 20H2+** | ✅ | **winget** | ✅ **полная поддержка** |
| **Windows 11** | ✅ | **winget** | ✅ **полная поддержка** |
| Windows 10 (до 20H2) | ❌ | — | ❌ **не поддерживается** |

> **Важно:** Начиная с версии 1.0 поддержка Windows 7, 8.1 и старых сборок Windows 10 прекращена. Лаунчер требует наличия `winget` (App Installer).

---

## 🚀 Быстрый старт (Net Install)

1. Скачайте последний релиз `launcher.exe` из раздела **Releases**.
2. Положите его в любую папку (например, `D:\WinGETLauncher`).
3. Запустите `launcher.exe` от имени Администратора.
4. Лаунчер сам скачает `update.bat` и базовые скрипты.
5. Выберите нужные программы и нажмите **«Установить выбранное»**.
