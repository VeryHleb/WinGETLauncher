# WinGET Launcher

**GUI-лаунчер для пакетной установки программ через `winget` и локальные дистрибутивы** (Windows 10 / 11).

**Последняя стабильная версия:** `2611:1`

---

## ✨ Возможности

- 🖥️ **Нативный GUI** на чистом Win32 API — без внешних зависимостей, компактные `.exe`
- 🎨 **Интерфейс Windows 8 Flat / Metro** — плоские кнопки, светлая палитра, шрифт Segoe UI и переключение языка (RU / EN)
- 🧠 **Автоопределение ОС:** проверка минимальной версии Windows (Windows 10 1809 / build 17763+)
- 🛠️ **Нативный установщик и апдейтер (`setup.exe`)** — установка из GitHub Releases, создание ярлыков, фоновая установка `winget` и бесшовное обновление через `setup.exe -update`
- ✅ **Выбор приложений** через удобные галочки в списке с группировкой по категориям
- 🔍 **Поиск через winget** — встроенное окно поиска с добавлением найденных пакетов в репозиторий
- 📁 **Локальные установщики (`source/exe`)** — быстрый доступ к папке локальных дистрибутивов прямо из настроек
- 📦 **Нативная работа с ZIP** — распаковка архивов релиза встроенными средствами Windows (`tar.exe` / PowerShell `Expand-Archive`)
- 📊 **Прогресс-бар N из N** — наглядное отображение хода пакетной установки
- 📝 **Живой вывод** `install_apps.bat` в правую панель лаунчера и подробный режим отладки (`-debug`)
- 🔒 **UAC-манифест** — автоматический запрос прав администратора при старте

## 🖥️ Поддерживаемые системы

| ОС | Лаунчер | Пакетный менеджер | Установка |
|---|---|---|---|
| **Windows 10 1809+ (build 17763+)** | ✅ | **winget** | ✅ **полная поддержка** |
| **Windows 11** | ✅ | **winget** | ✅ **полная поддержка** |
| Windows 10 (до 1809) / 7 / 8.1 | ❌ | — | ❌ **не поддерживается** |

> **Примечание:** Если `winget` (App Installer) отсутствует в системе, `setup.exe` при установке или `launcher.exe` при первом запуске автоматически предложат установить его через встроенный скрипт `install_winget.bat`.

## 🚀 Быстрый старт

1. Скачайте **`setup.exe`** из раздела **Releases**.
2. Запустите `setup.exe` (при необходимости выберите директорию установки и создание ярлыков) и нажмите **«Установить»**.
3. Установщик загрузит актуальный релиз с GitHub, развернёт скрипты из `files.txt` и при необходимости установит `winget`.
4. Запустите **`launcher.exe`**, отметьте нужные программы и нажмите **«Установить выбранное»**.
5. Для обновления в дальнейшем откройте **«Настройки» → «Проверить обновления»** — лаунчер автоматически передаст управление `setup.exe -update`.
