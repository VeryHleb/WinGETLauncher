# ============================================================
#  Winget Installer — Repository
#  Репозиторий приложений для установки через winget
# ============================================================
#
#  Формат строки:
#      winget.id|Отображаемое имя
#
#  Примеры:
#      Discord.Discord|Discord
#      Valve.Steam|Steam
#
#  Правила:
#    • Строки, начинающиеся с #, игнорируются.
#    • Пустые строки игнорируются.
#    • Если часть после | отсутствует, будет показан сам winget ID.
#    • Разделитель | (вертикальная черта) — обязателен, если хотите
#      задать своё отображаемое имя.
#
# ============================================================
