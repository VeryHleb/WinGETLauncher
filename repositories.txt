# ============================================================
#  Winget Installer — Repository
#  Репозиторий приложений для установки через winget/choco
# ============================================================
#
#  Формат строки:
#      winget.id|choco.id|Отображаемое имя
#
#  Примеры:
#      Discord.Discord|discord|Discord
#      Valve.Steam|steam|Steam
#
#  Правила:
#    • Строки, начинающиеся с #, игнорируются.
#    • Пустые строки игнорируются.
#    • Если часть после | отсутствует, будет показан сам winget ID.
#    • Разделитель | (вертикальная черта) — обязателен.
#
# ============================================================
