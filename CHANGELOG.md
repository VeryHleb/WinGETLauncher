# Changelog

Все значимые изменения проекта WinGET Launcher.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.2] — 2026-11-07

Релиз стабильной версии 1.2 с полностью обновленной архитектурой сетевой установки и нативной работой с архивами.

### ✨ Добавлено

* **Автономный сетевой установщик (`net_install.bat`).** Скрипт разворачивает проект с нуля по списку `source/net_install.txt`, запускает лаунчер и самоуничтожается.
* **Нативная распаковка ZIP-архивов.** Переход на формат `.zip` (`Winget.zip`), который распаковывается штатным встроенным инструментарием Windows (PowerShell `Expand-Archive` / Проводник) без использования сторонних консольных утилит.

### 🔧 Изменено

* **Обновлена структура списков.** Использование отдельных списков для обновления (`source/files.txt`) и сетевой установки (`source/net_install.txt`).
* **Формат `repositories.txt`.** Упрощение до 2 колонок (`winget.id|Отображаемое имя`) в связи с полным отказом от Chocolatey.

### 🗑️ Удалено

* **Полностью удален 7-Zip (`7z.exe`, `7z.dll`).** Компоненты архиватора убраны из репозитория за ненадобностью, так как система теперь полностью полагается на встроенный функционал Windows.
* **Скрипт переустановки (`reinstall.bat`).** Утилита удалена; задачи восстановления и разворачивания переданы `net_install.bat` и `update.bat`.

## [1.2-alpha] — 2026-11-02

### ⚠️ Основное изменение

* **Прекращена поддержка Windows 7 и 8.1.** Целевая система — Windows 10 (22H2, сборка 19045+) и Windows 11.

### ✨ Добавлено

* **Проверка версии Windows при запуске.** Блокировка запуска на устаревших ОС с выводом понятного сообщения.
* **Отдельный скрипт обновления `update.bat`.** Дожидается закрытия `launcher.exe`, скачивает обновления из `source/files.txt` с использованием временных файлов `.new` и перезапускает лаунчер.
* **Подробное логирование.** Расширенное отслеживание статуса обновлений в `update_debug.log`.

### 🔧 Изменено

* Обновлен манифест приложения (`app.manifest`), удалены устаревшие ОС.

### 🐛 Исправлено

* Проблема с кодировкой в `.bat` скриптах при вызове `chcp 65001`.

## [1.1-alpha] — 2026-10-15

### ✨ Добавлено

* **Автоопределение ОС и пакетного менеджера.** Выбор `winget` для Windows 10+ или `chocolatey` для Windows 7/8.1.
* **Встроенный поиск пакетов.** Окно поиска с интеграцией `winget search` и возможностью добавления приложений в репозиторий.
* **Категории приложений.** Графическое разделение списка приложений по секциям (`[Общение]`, `[Игры]` и т.д.).
* **Автообновление через GitHub.** Чтение `version.txt` и загрузка обновлений по списку `source/files.txt`.

### 🐛 Исправлено

* Исправлены ошибки подсчета прогресс-бара («14 из 10»).
* Устранено зависание `errorLevel` в скриптах установки (`DelayedExpansion`).
* Устранен BOM-маркер при записи `version.txt` через бинарный режим MinGW.
* Исправлен ложный вывод статуса копирования `TgWsProxy`.

### 🗑️ Удалено

* Автоповышение прав через `Start-Process` в `install_apps.bat` (заменено на проверку манифеста).
