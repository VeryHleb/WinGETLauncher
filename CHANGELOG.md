## [1.2 alpha win7] — 2026-10-10

Крупное обновление: кроссплатформенность, автообновление, категории и исправления.

### ✨ Добавлено

- **Определение ОС при запуске.**
  Лаунчер определяет версию Windows и автоматически выбирает пакетный менеджер:
  `winget` для Windows 10 (build 17763+) и Windows 11,
  `chocolatey` для Windows 7 SP1 / 8.1 / старых Windows 10.
- **Автоустановка Chocolatey.**
  Если `choco` не установлен — скрипт ставит его через официальный установщик.
- **Система автообновлений через GitHub.**
  При запуске читается `version.txt` с `github.com/VeryHleb/WinGETLauncher`,
  сравнивается с локальной версией. Если они различаются — предлагается обновление.
- **Файл `source/files.txt`** — список файлов для автообновления.
  Лаунчер скачивает каждый файл из списка и сохраняет по нужному пути.
- **Автосоздание папок при обновлении.**
  Функция `EnsurePathExists` создаёт `source\`, `source\exe\` и любые вложенные папки.
- **Категории приложений в списке.**
  Поддержка секций `[Общение]`, `[Игры]`, `[Мультимедиа]` и т.д. —
  заголовки отображаются как `── Название ──`.
- **Поиск приложений через `winget search`.**
  Отдельное окно с полем ввода, индикатором загрузки, списком результатов
  и кнопкой «Добавить в репозиторий».
  Запуск поиска по **Enter**.
- **Кнопка «Открыть репозиторий».**
  Открывает `source\repositories.txt` в Блокноте.
- **Кнопка «Проверить обновления».**
  Ручной запуск проверки версии в любой момент.
- **Прогресс-бар `N из N`** — точно по числу выбранных пакетов.
- **Зелёный статус-бар «Successfully · Установка завершена»** при успехе.
- **Маркер `[BAT_DONE] rc=X`** в конце `install_apps.bat` —
  лаунчер корректно понимает завершение работы.
- **Автоочистка логов** старше 30 дней (`forfiles /d -30`).
- **Retry-логика для установки.** До 3 попыток для `winget install` и `choco install`.
- **Отладочный лог `update_debug.log`** — для диагностики обновлений.

### 🔧 Изменено

- **Формат `repositories.txt`** расширен до 3 колонок:
  `winget.id|choco.id|Отображаемое имя`.
  Обратная совместимость со старым форматом сохранена.
- **Улучшенный парсер `repositories.txt`.** Понимает `|`, `,`, `;` и BOM.
- **Запись `version.txt` без BOM** — через бинарный режим
  `_wfopen(..., L"wb")` + `WideCharToMultiByte(CP_UTF8, ...)` + `fwrite`.
- **Интерфейс в стиле Windows 7 Aero:**
  градиентный фон окна, owner-draw кнопки с подсветкой при наведении,
  шрифт Segoe UI 9pt, скруглённые углы.
- **Заголовок окна** теперь показывает пакетный менеджер и версию ОС:
  `WinGET Launcher — winget [Windows 10.0 (build 19045)]`.

### 🐛 Исправлено

- **Счётчик прогресса «14 из 10».**
  Раньше каждая строка `[OK]` увеличивала счётчик. Теперь — один раз на пакет.
- **Неверный финальный код возврата `winget`.**
  Из-за delayed expansion `errorLevel` «залипал» на 0.
  Установка вынесена в подпрограмму `:ProcessOne` с `setlocal`,
  код берётся сразу после `winget install`.
- **Ложный `[OK] Copy successful` для TgWsProxy.**
  Теперь проверяется реальное наличие файла после копирования.
  Перед копированием запускается `taskkill` для занятого процесса.
- **BOM в `version.txt`.**
  Раньше MinGW добавлял BOM в режиме `ccs=UTF-8`, из-за чего сравнение версий
  всегда показывало разницу.
- **Мелькание окна `cmd` при установке.**
  Убрано автоповышение прав в `install_apps.bat`
  (лаунчер уже запущен от админа через манифест).
- **Мусорные строки в `repositories.txt`.**
  Умный парсер отбрасывает нечитаемые конструкции.

### 🗑️ Удалено

- **Автоповышение прав через `Start-Process -Verb RunAs`** в `install_apps.bat`.
  Заменено на предупреждение `[WARN] Not running as Administrator`.
- **Папка `logs/` из отслеживания Git** (через `.gitignore`).

### ⚠️ Известные ограничения

- **`winget` не поддерживает Windows 7.**
  Лаунчер запускается, но установка через winget на Win7 невозможна —
  используется Chocolatey.
- **TgWsProxy** устанавливается **только если выбран Telegram**.
- **AIMP** в winget имеет битую ссылку (404) — установите через Chocolatey или вручную.

## [1.0 alpha win7] — 2026-10-08

Первый публичный релиз.

### ✨ Добавлено

- GUI-лаунчер на Win32 API.
- Список приложений с чекбоксами.
- Установка через `winget` в тихом режиме.
- Прогресс-бар установки.
- Живой вывод `install_apps.bat` в правую панель.
- Логирование в `logs\`.
- Файл-репозиторий `repositories.txt`.
- Автозапуск TgWsProxy при выборе Telegram.
- UAC-манифест (`requireAdministrator`).
- Стилизация под Windows 7 (частичная).

### 🐛 Известные проблемы

- Прогресс мог превышать общее число пакетов.
- `errorLevel` в `.bat` давал неверный итоговый код.
- BOM в `version.txt` (ещё до системы обновлений).
- Мелькало окно `cmd` при перезапуске `.bat`.
- Ложные `[OK]` при неудачном копировании TgWsProxy.
